# Reminder time picker manual checks

Native UI has not been run or tested for this change. No builds or tests were run, as requested.

The shared picker is used by the note/card ReminderSheet, Calendar start/end fields, and Plan morning/evening reminder settings on iOS and Android. Done updates the reminder sheet or Calendar draft; their existing Save actions still validate and schedule. Plan settings retain their existing immediate save on confirmation.

1. Open a note or card reminder, choose a custom date/time, then tap Time. Check the full-screen dotted background, safe areas, yellow Set Time title, existing mascot/accessory peeking behind the wheels, and clock illustration. Confirm no feet or mascot overlap with the selected digits.
2. Check that the current time initializes correctly. Drag both wheels slowly, flick them quickly, and reverse direction. Check centered snapping and wrapping from 12 to 01 and 59 to 00 in either direction. Try Done during inertia; the nearest displayed values should be committed once.
3. Switch AM/PM repeatedly. Hour and minute must stay unchanged. Confirm 12:00 AM returns midnight and 12:00 PM returns noon to the sheet. The picker should remain in 12-hour format on a device configured for 24-hour time.
4. Change the wheels and period, then Cancel, use the back button, and use Android hardware Back. Reopen each time: the previous sheet time must be preserved. Confirm Done changes the draft, while closing the reminder sheet without saving does not persist it.
5. Save a future reminder using the existing sheet action; check existing validation, permissions, and notification behavior. Check editing an existing reminder, and Android's date-then-time flow.
6. Check a small phone, a larger screen, landscape, large text, dark appearance, and an RTL language. Confirm scrolling can reveal all controls, Hours remain left of Minutes, and touch targets stay usable. With VoiceOver/TalkBack, use wheel increment/decrement actions and check selected AM/PM announcements. With Reduce Motion enabled, check a static mascot and immediate selections; toggle it while open and during Done to check dismissal still completes.
7. In Calendar, create and edit a timed note. Open both Starts and Ends and confirm the shared picker initializes from each field. Cancel must preserve the draft. Moving Starts must retain the existing duration adjustment; Ends at 12:00 AM must retain end-of-day behavior. Save/reopen and check the times. Also open a custom Calendar reminder and confirm it uses the same picker. Date selection and All day should still work as before.
8. In Settings → Plan, enable the morning/evening reminders and open each Time row. Confirm each uses the shared picker and its own saved time. Cancel must preserve it; Done must save only that reminder's time. Reopen settings to check persistence, including noon and midnight. Existing notification permission prompts should still occur only when enabling reminders.
9. With the development console open, open Calendar's existing-note list, select a note, then open Starts, Ends, and a custom reminder time. Also open the picker from Plan settings. Check that no nested VirtualizedList warning appears. Flick each bounded wheel through its wrap point, then scroll the surrounding screen outside the wheels on a small screen: each gesture should move only its intended area.
